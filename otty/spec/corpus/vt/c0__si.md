# SI — Shift In [​](#si-—-shift-in)
****``********
|  |  |
| --- | --- |
| Byte | 0x0F |
| Mnemonic | SI |
| Otty support | ✓ |

## Description [​](#description)

Switches the active character set back to **G0** (the default — usually US ASCII). Pairs with [SO](/vt/c0/so), which switches to G1.
